=============
Downwind API
=============

The Downwind API (dw-api) is a component of the Downwind framework that handles the automatic generation of API endpoints based on CQRS (Command Query Responsibility Segregation) principles. It serves as the interface layer of the framework, automatically creating RESTful endpoints from your command and query handlers.

Core Features
------------

* **Automatic Endpoint Generation**: Creates API endpoints from command and query handlers
* **CQRS Integration**: Seamless integration with the CQRS pattern
* **Type Safety**: Strong typing and validation through Pydantic models
* **Framework Agnostic**: Can be integrated with any Python web framework
